# 随机静态站与 XHTTP 本地验收

日期：2026-10-07。Xray v26.9.30，Nginx 1.26.3；全部使用隔离回环端口和临时生成的合成凭据。
没有安装 systemd 单元，没有改动用户运行节点。测试结束只停止本轮进程并删除临时目录。

## 通过项

- 四种 AI 类型（新闻、硬件、研究、综合）均有可达的本地导航、历史列表和样式；固定种子可重现，
  多个种子产生不同页面。只有外部来源链接，没有外部脚本/字体/图片请求。
- REALITY → SNI router → Nginx 的 PROXY 协议链路，静态主页/历史列表匹配本地文件，未知/隐藏路径 404。
- 本地模拟允许来源可访问，相同 SNI 的其他来源被拒绝，未知 SNI 拒绝，真实伪装站中继保留。
- REALITY Vision 和 XHTTP packet-up + VLESS Encryption 分别完成超过 2 MB 下载及上传。
- 两条节点的错误 UUID 均无法完成请求。
- Nginx 到 XHTTP 使用证书校验；损坏的信任文件不能通过配置检查。
- 后端停止后 XHTTP 路径返回 502，未被替换为静态网站内容。
- 实际 prepare-node-files 入口生成默认网站、私有代理配置及正确的 8003→8002 拓扑，公开静态文件
  不包含测试 UUID、VLESS Encryption 或私有 XHTTP 路径。CF 地址下载在该测试中由合成 CIDR 替代。
- `--website off` 保留原 8002 直连拓扑。
- RSS/Atom 解析、硬件筛选、来源日期、去重、HTML 清洗、XML 实体拒绝、来源域名限制、304 缓存通过测试。
- 全部抓取失败和渲染失败保留旧版本；部分来源失败保留其旧条目；样式不随内容刷新变化。
- 三天到期检查使用持久化时间，未到期不抓取，超过三天才允许定时刷新。
- 原子更新后的资讯立即通过 Nginx 访问，样式和服务进程不变；定时器与资讯服务通过 systemd 单元语法检查。
- 公开源采集实测中 5 个成功、Hugging Face 暂时失败，生成 84 条去重资讯；未冒报全部来源成功。
  最新来源日期为 2026-10-06。原文和 RSS 内容未进入模型调用，也未混入节点配置。
- 原私密导出、安装器/下载器契约、ASN 测试及原 SNI 路由集成测试继续通过。

本地测试服务位于回环地址，测试配置只为该 HTTPS 下载服务的 IP/端口添加 freedom finalRules allow；
正式配置的内网访问限制没有更改。该测试例外不能复制到实际部署配置。
